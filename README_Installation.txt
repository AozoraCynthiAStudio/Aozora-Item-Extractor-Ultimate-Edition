Aozora Item Extractor Ultimate Edition v1.0.3
Requirements: Fallout 4, matching F4SE and Address Library, VC++ x64 runtime. MCM optional.
Install the English core using a mod manager; enable AozoraItemExtractor.esp and launch through F4SE.
Bind the menu hotkey in MCM or use the Aozora Item Extractor Aid item in Pip-Boy.
Left: Return / Batch Return / Return All. Right: Take / Batch Extract / Take All.
Keyboard E/Q/R actions; A/D panes; Z/C categories. Gamepad A/Y/X actions; LT/RT categories.
Batch modal: A/D or left/right, E confirm, Tab cancel.
CHS Patch overrides the English core: disable old CHS_Name/CHS_Tips patches. It includes translated text and the same ESP with launcher display names translated; no extra plugin slot. Chinese game fonts required.
