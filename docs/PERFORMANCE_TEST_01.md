# 主线性能优化测试 01

基于 1.0.6，独立测试包，不包含 Examine 观察或预览代码。

## 修改

- 左栏只查询本次会话中有净提取数量的物品，不再为整个背包解析图标、构建行并排序。
- 按插件缓存静态物品行，重新进入时复用；扫描或读档重置时清理。弹药数量和武器赠送设置仍读取当前配置。
- FIS 标签使用索引查找；关键词匹配遍历物品关键词，保留后定义规则的优先级。
- AS3 全部分类直接使用现有数组，其他物品分类缓存筛选结果，收到新物品数据后失效。
- 增加 PERF_ITEM_ROWS、PERF_SNAPSHOT、PERF_GFX 分段耗时日志。

## 测试重点

安装完整测试核心包，再覆盖对应汉化补丁。

1. 冷启动后首次进入两千条目左右的插件，观察等待时间。
2. 返回插件页后再次进入同一插件，比较等待时间。
3. 切换类别、滚轮/拖动/右摇杆滚动、按物品名称搜索并进入，确认选中行正确。
4. 提取、批量提取、归还、全部归还，确认左栏数量与背包一致。
5. 修改 MCM 弹药数量后重新打开，确认显示及实际数量正确。
6. 读档后重复进入及提取，检查缓存未残留旧状态。

请保留 Documents/My Games/Fallout4/F4SE/AozoraItemExtractor.log，
其中包含完整的 PERF_GFX 日志；MO2 overwrite 下的日志可补充 native 阶段。

编译及打包不代表游戏内性能验收。首次仍会向 Scaleform 传输完整物品数组，
本版没有加入分页或异步读取游戏对象；若耗时集中在这部分，再依据实测进一步修改。
