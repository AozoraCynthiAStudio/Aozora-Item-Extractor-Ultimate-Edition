# Spike07：摄像机矩阵定位对照实验

Spike06证明网格移动有效，但ViewPointToRay生成的位置始终在视锥外。这并不能单凭日志断言AE地址或签名错误。

本版移除ViewPointToRay调用。使用渲染器摄像机world变换，将三个局部轴的正负方向转换为世界位置，用WorldPtToScreenPt3和PointInFrustum交叉校验。只有找到靠近画面中心且位于视锥内的位置才移动模型；无候选则记录失败，不盲目移动。保留警棍真实网格、异步加载和世界坐标附着，不放置世界物品或改背包/UI尺寸。

完全退出游戏，禁用旧实验包、启用本包。进入任意插件提取页，停留约10秒，提供截图与AIE_PreviewSpike.log。新版日志以PreviewSpike07开始，记录六个候选位置的投影/视锥结果。

编译/打包不代表AE运行验收。正式Data保持不变，实验开关默认关闭。
