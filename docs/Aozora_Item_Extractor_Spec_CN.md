# 青空物品提取器 SWF 重制规格

## 设计目标

把现有物品提取功能迁移到原生 Scaleform 菜单，界面参考“青空的侧边收藏栏”的扁平、清爽风格。结构优先，避免大块装饰和无关信息；辐射娘素材暂缓，后续由项目作者提供。

结构与布局以 `SWF Redux/物品提取器设计方案.png` 为准。页面由插件导航页和双栏提取页组成；提取页左栏是玩家背包，右栏是当前 MOD 的可提取物品。

## 页面结构

### 插件导航页

- 标题、全部/ESP/ESL 筛选、插件搜索与紧凑插件列表。
- 隐藏没有可提取物品的插件，按有效加载顺序倒序排列。
- 提供当前设备的简洁操作提示。

### 双栏提取页

- 左栏显示玩家当前持有、符合筛选规则的物品；物品行显示当前数量。
- 右栏显示当前插件的可提取物品；行内数量提示每次配置的提取组数。
- 左右栏各有独立类别筛选，避免一侧切换时另一侧内容意外变化。
- 选中栏位使用主题色高亮；左栏可退回数量受限时同时显示持有量和可退回量。
- 保留插件名称、分类、必要的转移提示和批量选择弹窗；不放作者信息、价值、重量、大型预览或实现说明。

类别：全部、武器、服装、辅助品、弹药、垃圾、杂项。

### 配色

- 默认跟随游戏 HUD 颜色。
- MCM 可切换到与 HUD 解耦的内置配色：避难所绿、琥珀终端、冰霜青、废土锈红、兰紫、冷白终端。
- 保持暗色底、细边线与克制的高亮；颜色变化不改变页面层级和组件布局。

## 转移与安全边界

- 单次转移按物品类别配置的组数量执行；批量选项基于 `1 / 10 / 50 / 100 / 1000`，并纳入当前配置数量和可用库存限制。
- 获取全部忽略当前类别筛选，处理当前插件全部有效物品；大型插件按批处理。
- 提取远程武器时添加其基础弹药 1000 发；近战、手雷和地雷不添加弹药。
- 菜单打开时捕获背包基线。左栏可退回数量不能超过本次菜单提取后仍持有的净增量，玩家进入菜单前持有的物品不可退回。
- 切换插件或回到导航页不清除本次提取记录；关闭菜单时结束会话并清理记录。
- 游戏对象在游戏线程中操作；界面只提交 FormID 和操作参数，不长期持有裸 `TESForm*`。
- 维持现有物品有效性、任务物品和不可携带记录过滤规则。

组数量配置位于 `Data/F4SE/Plugins/AozoraItemExtractor.ini` 的 `[ItemCount]` 段：

```ini
[ItemCount]
Weapon=1
Armor=1
Ammo=100
Aid=1
Grenade=1
Junk=1
Misc=1
```

## 输入与启动

- 支持键盘、手柄和鼠标。搜索框支持文本输入；列表行、类别标签和批量选项可用鼠标操作。
- 保留现有键盘与手柄导航、转移、批量、获取全部和返回操作。
- MCM 为可选项：用于绑定菜单热键与选择主题；Pip-Boy 启动物品始终可用。
- 菜单打开期间由原生 Scaleform 菜单管理游戏输入和暂停；退出时恢复游戏状态。

## 技术边界

- CommonLibF4 原生插件负责插件扫描、物品有效性、背包枚举、会话基线、转移、主题设置读取和 FIS 图标规则解析。
- `src/as3/` 中的 ActionScript 3 负责 Scaleform 页面绘制、焦点、筛选、搜索及交互；通过 GFx 对象回调与 Native 通信。
- 只编译一份英文键值 SWF。界面和 MCM 文本均使用 `$AIE_*` 键，核心包附带英文 `AozoraItemExtractor_en.txt`。
- 中文版是纯翻译覆盖补丁：覆盖同路径的 `Interface/Translations/AozoraItemExtractor_en.txt`，不携带 DLL、SWF、ESP 或脚本；依赖当前配置 `sLanguage=en`，MO2 中补丁优先级需高于核心包。
- FIS 图标缺失或加载失败时显示 SWF 内置分类图形。
- Prisma UI HTML/CSS/JavaScript 旧页面不再参与当前界面构建。
