# v1.0.7

- 优化物品列表加载和会话归还列表刷新。
- Improved item-list loading and session-return refreshes.
- MCM 新增图标库选择：FIS / 内置图标。
- Added an MCM icon library option: FIS / Built-in.

FIS 在打开物品较多的插件时可能需要一定解析时间，具体取决于模组环境和 FIS 规则。内置图标开销更低，实测加载基本无感。
FIS may take time to process large item lists, depending on your mod setup and FIS rules. Built-in icons have less overhead, with virtually no noticeable loading in our tests.
