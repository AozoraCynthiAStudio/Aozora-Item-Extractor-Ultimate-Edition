# Preview Spike04（实验包，非正式发布）

目标：在提取页显示固定的原版10mm手枪，验证引擎3D链路。

Spike03在AE测试中没有显示模型，日志指出根节点包围球无效。Spike04检查最多512个节点、最大32层，在第0/60/180帧记录节点类型、名称、网格尺寸、剔除状态和渲染数据指针。若子网格具有有效尺寸，则用保守包围球尝试将模型移至摄像机中心。若没有有效网格，不猜测尺寸、不宣称加载成功。

沿用引擎异步Load3D和Interface3D，不修改提取器Movie viewport，不添加物品到背包。实验编译开关默认关闭。正式Data中的DLL未替换。

测试：完全退出游戏，用本实验包替换前一个实验包，重启并进入任意插件的提取页，停留约10秒后退出菜单。查看是否出现10mm手枪；无论是否显示，请提供Data/F4SE/Plugins/AIE_PreviewSpike.log。日志采取追加写入，以PreviewSpike04开始的段落为本次结果。

已验证：Windows本地编译、打包。尚未验证：AE实际画面、纹理、运行安全性及退出清理。仅建议在测试配置中使用；测试后可禁用本包恢复正式版本。
