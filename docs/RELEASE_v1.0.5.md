# v1.0.5

## 更新 / Changes

- **长列表滚动**：支持鼠标拖动滚动条、点击轨道翻页；悬停时提亮拉杆，并扩大鼠标响应范围。手柄可用右摇杆上下滚动当前焦点所在的列表，推得越多滚动越快。滚动后选中项保持完整可见。
- **Long-list scrolling**: Drag the scrollbar or click its track to page through lists. Hover highlighting and a wider mouse hit area make it easier to grab. Use the controller's right stick to scroll the focused list; stronger input scrolls faster. The selected row stays fully visible.

- **中文输入兼容**：改进搜索框的文本输入与焦点处理。[Chinese Input（RIME）](https://www.nexusmods.com/fallout4/mods/90872) 和 [NA Input Support](https://www.nexusmods.com/fallout4/mods/99121) 均已测试通过。如果你希望兼容其他输入模组，欢迎留言并提供模组链接。
- **Chinese input compatibility**: Improved text input and focus handling in the search box. [Chinese Input (RIME)](https://www.nexusmods.com/fallout4/mods/90872) and [NA Input Support](https://www.nexusmods.com/fallout4/mods/99121) have both been tested successfully. For other input mods you would like supported, leave a comment with a link.
