Aozora模组物品提取器 终极版 v1.0.4
先安装英文主体并启用 AozoraItemExtractor.esp，通过 F4SE 启动游戏。
需要匹配游戏版本的 F4SE、Address Library 及 VC++ x64 运行库。MCM 可选。
在 MCM 中绑定菜单热键，或使用 Pip-Boy“辅助”分类中的启动物品。
左栏：归还／批量归还／全部归还；右栏：提取／批量提取／全部提取。
E/Q/R 对应三个操作，A/D 切栏，Z/C 切分类；手柄 A/Y/X 操作，LT/RT 切分类。
数量弹窗：A/D 或左右切换，E 确认，Tab 取消。
中文补丁放在英文主体之后覆盖，并停用旧 CHS_Name／CHS_Tips 补丁。需要游戏中文字体支持。
终极版从 v1.0.0 开始编号，内部插件、脚本和表单 ID 沿用。
